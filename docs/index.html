    애니메이션 · 전환

    뜻이 있을 때만 움직입니다.

    Fade·Push·Morph 전환과 항목별 나타나기를 PowerPoint 기본 효과로 넣습니다. 덱 전체를 motion 한 단어로 정하고, 회전·튕기기 같은 효과는 쓰지 않습니다. 아래 영상은 PowerPoint 가 그대로 재생한 화면입니다.

    none움직임 없음. 인쇄·배포용
    subtle짧은 Fade, 내용이 차례로 나타남
    build클릭마다 항목이 하나씩. 연수·수업
    dynamic장이 바뀔 때 Push, 숫자 Zoom
    morph장 번호·큰 숫자가 이어서 움직임

    시작하기

    파이썬만 있으면 됩니다.

    PowerPoint 없이도 .pptx 를 만듭니다. PowerPoint 가 있으면 미리 보기·실측 점검·PDF·MP4 까지.

    AI 프로그램에 연결

    설치된 AI 를 찾아 MCP 도구와 스킬을 등록합니다(설정 파일은 백업 후 수정).

    git clone https://github.com/ZZombie04/pptx_maker
cd pptx_maker
python -m pptx_maker setup --fonts

    명령줄로 직접

    용도별 뼈대를 받아 빈칸을 채우고 만듭니다.

    python -m pptx_maker plan pitch --topic "주제" -o spec.json
python -m pptx_maker build spec.json --preview

    웹 AI 에 올리기

    ChatGPT·Claude.ai·Gemini 처럼 코드 실행이 되는 AI 에 zip 하나를 올리고 안내 글을 붙여 넣습니다.

    python -m pptx_maker pack -o dist
