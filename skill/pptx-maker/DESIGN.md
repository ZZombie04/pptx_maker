# 디자인 원칙 — 사람이 만든 것 같은 발표 자료

pptx_maker 의 기본값은 이 원칙을 따르도록 만들어져 있다. 명세나 파이썬으로 덱을 짤 때도 같은 원칙을 지킨다.
어떤 AI 모델이 쓰든 결과가 같도록, 판단이 필요한 곳은 엔진이 대신 정한다(테마·장 색·글꼴·대비·줄바꿈·움직임). 사람(또는 AI)이 할 일은 **내용 설계**다.

## 0. 순서(가장 중요)

1. **용도를 고른다** — `recipes`(24가지). 용도가 테마·움직임·흐름·쓰는 법을 정한다.
2. **뼈대를 받는다** — `plan 용도 --topic "주제" --minutes 40` → TODO 가 든 명세. TODO 만 채운다.
3. **만들고 점검한다** — `build --preview` → 오류·경고 0, 점수 90 이상.
4. **눈으로 본다** — 모아 보기 그림(sheet_XX.png)을 열어 모든 장을 확인한다.

## 1. 내용이 먼저

- **제목은 결론형 한 문장**(30자 안팎). "현황" 대신 "평균이 4점대면 오를 자리가 없습니다". 제목만 이어 읽어도 이야기가 되어야 한다.
- 제목 위 작은 머리말(kicker)은 장 이름이 자동으로 들어간다. `topic` 을 주면 `장 이름 · topic`.
- **한 장 한 메시지**, 근거는 2~5개. 넘치면 장을 나눈다(엔진이 글머리 7·표 9·행 6개를 넘으면 자동으로 나눈다).
- 모든 장에 **발표자 노트**(말할 내용). 화면에는 핵심만, 설명은 노트로.
- 숫자에는 단위·기준·출처. 출처는 아래 한 줄(`source`).
- 지어 낸 수치·사례는 쓰지 않는다. 예시 수치면 "(가상)"이라고 밝힌다.

## 2. 테마 18가지 — 상황에 맞는 얼굴

| 테마 | 어울리는 자리 | 얼굴 |
|---|---|---|
| editorial | 연수·정책·결과 보고·교육 자료(기본) | 흰 바탕·연회색 면, 장마다 포인트 색 |
| studio | 교사 연수·직무 교육·워크숍 | 발표용 글꼴, 옅은 회색 바탕 흰 판, 실습 장은 어두운 판 |
| civic | 공공기관·교육청·행정 보고 | 정부 남색, 개조식 □ ○ |
| report | 성과·데이터·주간 보고 | 대시보드 카드, 상태 색은 상태에만 |
| consulting | 경영 전략·이사회 보고 | 액션 타이틀, 아래 핵심 막대, 밀도 높은 표 |
| pitch | 투자 유치·창업·공모전 | 검정 표지, 신호 주황, 아주 큰 숫자 |
| keynote | 제품 발표·기술 설명회 | 검정 바탕, 사진 전면 + 어둡게 덮기 |
| academic | 학회·논문 심사·연구 보고 | 명조 제목, 그림 번호, 쪽수 '12 / 34' |
| classroom | 초등·중등 수업·방과후 | 둥근 제목 글꼴, 활동마다 정한 색 |
| magazine | 브랜드 이야기·인문·문화 | 굵은 명조, 큰 세리프 숫자, 큰따옴표 |
| swiss | 디자인·건축·포트폴리오 | 12단 격자, 검정·빨강, 아주 굵은 글자 |
| tech | 개발자·AI·IT 교육 | 먹색 바탕, 라임, 고정폭 머리말, 코드 블록 |
| festival | 축제·체육대회·공연 | 검은고딕 제목, 큰 색 면과 도형 |
| poster | 캠페인·선언·동기 부여 | 화면 가득한 글자, 장마다 한 색 면 |
| minimal | 강연·철학·오프닝 | 넓은 여백, 가는 글자, 남청 하나 |
| calm | 상담·심리·건강·복지 | 세이지 바탕, 고운바탕·고운돋움, 빨강 없음 |
| noir | 시상식·졸업식·의전 | 먹색 바탕, 샴페인 골드, 가운데 정렬 |
| gallery | 전시·브랜드·기획서 | 칠하지 않고 선과 여백, 모서리 0 |

테마를 고르지 않으면 `intent`(용도)가, 용도도 없으면 주제 낱말이 테마를 정한다(`suggest "주제"`).
같은 내용도 `--theme` 만 바꾸면 전혀 다른 덱이 된다. 표지·장 표지·한 문장 슬라이드의 모양(variant·mode)은 테마마다 다르다.

## 3. 색: 중립색 + 장마다 포인트 색 하나

바탕은 흰색·연회색·검정(테마 중립색), 여기에 **장(섹션)마다 내용에 맞는 포인트 색 하나**. 한 장 안에서는 포인트 색이 하나뿐이다.
장 색을 적지 않으면 엔진이 장 제목의 뜻에 맞춰 테마 팔레트에서 **겹치지 않게** 고른다.

| 내용 | 포인트 색 | 이유 |
|---|---|---|
| 제도·정책·법·공식 | navy · govblue | 권위·안정 |
| 계획·설계·구조·과정 | teal · workshop | 설계도의 차분함 |
| 데이터·분석·증거·디지털 | blue · cobalt · dash | 명료·신뢰 |
| 고쳐 쓰기·주의·문제점 | crimson · red · tomato | 빨간 펜 |
| 성장·윤리·환경·완성 | green · forest · sage | 안전·성장 |
| 일정·마감·실행·점검 | amber · sun | 시간·에너지 |
| 축하·의전·고급 | gold | 격식 |
| 창의·문화·예술 | klein · plum · violet | 아껴 쓴다 |
| 부록·요약·참고 | graphite · ink | 절제 |

- 브랜드 색이 있으면 `"accent": "#0E7C7B"` — 엔진이 진한 색·옅은 색·면 색·대비 색을 한 가족으로 만든다.
- **표지와 마지막 장은 같은 대표 색**.
- **데이터 그래프 색은 장 색과 따로**: 덱 전체에서 같은 뜻에 같은 색(예: 사전=옅은 색, 사후=진한 색).
- 대비는 엔진이 지킨다: 작은 글자 4.5:1, 큰 글자 3:1. 흰 글자를 올리는 면은 대비가 되는 진한 색(accent_chip)으로 바뀐다.
- **하지 않는 것(AI 티)**: 보라→파랑 그라데이션, 무지개색, 그림자 남발, 이모지 아이콘, 아이보리 바탕+코랄, 장식용 색 띠, 제목 밑줄 장식, 유리 효과, 모든 장이 같은 카드 격자.

## 4. 구성: 반복을 피하고 리듬을 만든다

- **같은 구성 3장 연속 금지.** 표·흐름·큰 숫자·비교·사진·한 문장·인용·시간선·도식을 섞는다(48가지 종류).
- **카드 격자는 정말 나란한 정보일 때만.** 그 밖에는 선으로 나눈 목록(list2)·번호 행(rows)·핵심 정리(takeaways).
- 장의 리듬: `장 표지 → 질문(한 문장) → 근거 3~8장 → 정리(한 문장·실습·점검)`.
- 장 표지는 사진 위치를 좌우로 번갈아 둔다(자동). 장마다 다른 사진, 같은 사진 두 번 금지(점검이 잡는다).
- 사진은 **과정이 보이는 장면**. 사진 위 글자는 엔진이 어둡게 덮는다. 흑백(`tone:"mono"`)·이중톤(`"duo"`)으로 덱 색에 맞춘다.
- 강조 면(장 색으로 칠한 상자)은 한 장에 하나(`hi`).
- 아이콘은 선 아이콘 한 벌(2,000여 개, 한국어 낱말 430개로 찾기). 이모지는 쓰지 않는다.

## 5. 글자(한국어)

- 테마마다 글꼴 짝이 정해져 있다: Pretendard·Freesentation·SUIT·Wanted Sans·IBM Plex Sans KR·Paperlogy(고딕), 나눔명조·고운바탕·송명(명조), 검은고딕·도현·주아(제목용), 고운돋움, D2Coding·JetBrains Mono(코드), Bebas Neue·Anton·DM Serif Display(라틴 숫자).
- 글꼴은 처음 쓸 때 공개 저장소에서 자동으로 받아 둔다(`fonts install` 로 이 PC 에 설치, `--pack-fonts` 로 발표 PC 용 꾸러미). 줄바꿈 계산은 글꼴마다 실측한 폭으로 한다.
- 크기: 제목 28~34pt · 본문 15~18pt · 표 12.5~14pt · 보조 12~13pt · 출처·꼬리말 9~9.5pt. 9pt 미만 금지.
- **줄바꿈은 어절 단위**(엔진이 PowerPoint 와 같게 미리 나눈다).
- 굵게(`**강조**`)는 한 문단에 한두 군데. 고정폭(`` `코드` ``)은 명령·파일 이름에만.
- 날짜 `2026. 10. 5.`, 숫자와 단위는 붙여 쓴다(`50쪽`, `78.3%`).

## 6. 움직임(애니메이션·전환)

움직임은 **뜻이 있을 때만**. 덱의 `motion` 하나로 정한다.

| motion | 전환 | 나타나기 | 어울리는 자리 |
|---|---|---|---|
| none | 없음 | 없음 | 인쇄·배포용, 주간 보고 |
| subtle | 짧은 Fade(표지·장 표지는 조금 길게) | 내용이 차례로 저절로 페이드(클릭 없음) | 보고·강의(기본) |
| build | Fade | 본문·숫자·그래프 무리가 클릭마다 나타남 | 연수·수업·설득 |
| dynamic | 장이 바뀔 때 Push, 장 안은 Fade | 저절로: 글 떠오르기, 숫자 Zoom, 막대·선 Wipe | 피치·행사·캠페인 |
| morph | Morph(같은 이름 도형이 이어서 움직임) | dynamic 과 같음 + 장 번호·진행 표시·큰 숫자가 이어짐 | 제품 발표·키노트 |

- 한 덱에 전환은 한두 가지. 회전·튕기기·날아오기는 쓰지 않는다.
- 행사장 화면은 `auto_advance`(초)와 `loop`.
- `--video` 로 MP4(PowerPoint 필요), `--pdf` 로 PDF.

## 7. 배치(960×540pt 기준)

- 좌우 여백 44pt. 머리말 34 · 제목 56 · 이끄는 말 98 · **본문 148~470** · 출처 478 · 꼬리말 513.
- 왼쪽 맞춤이 기본. 가운데 맞춤은 한 문장·의전·표지에만.
- 꼬리말: 테마마다 진행 막대·쪽수·점·고정폭 등. `footer:false` 로 끈다.

## 8. 엔진이 자동으로 점검하는 것

| 점검 | 기준 |
|---|---|
| 넘침 | 글자를 줄여도 상자에 안 들어가면 오류 |
| 겹침 | 글자끼리 3pt 넘게 겹치면 오류 |
| 벗어남 | 슬라이드 밖으로 나간 글자 |
| 작은 글자 | 9pt 미만 |
| 대비 | 작은 글자 4.5:1, 큰 글자 3:1, 9~10pt 메모성 글자 2.4:1 |
| 색 수 | 한 장에 포인트 색 가족 둘 이상 |
| 반복 | 같은 종류 3장 연속, 같은 사진 두 번 |
| 글 많음 | 한 장 글자 420자 넘음 |
| 빈칸 | TODO 가 남음, 아이콘 이름 없음, 사진 없음 |
| 노트 | 발표자 노트 없음 |
| 실측(PowerPoint 있을 때) | PowerPoint 가 그린 실제 줄 수 = 엔진 예상 줄 수 |

점수(100점): 구성 25 · 다양성 20 · 글 20 · 디자인 점검 25 · 전달 10. `score 명세.json`. 오류·경고는 모두 고친 뒤 넘긴다.
