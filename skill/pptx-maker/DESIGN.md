# 디자인 원칙 — 사람이 만든 것 같은 발표 자료

pptx_maker 의 기본값은 이 원칙을 따르도록 만들어져 있다. 명세나 파이썬으로 덱을 짤 때도 같은 원칙을 지킨다.

## 1. 내용이 먼저

- **제목은 결론형 한 문장**(30자 안팎). "현황" 대신 "평균이 4점대면 오를 자리가 없습니다".
- 제목 위 작은 머리말(kicker)은 `장 이름 · 주제`. 장 안에서 어디쯤인지 알려 준다.
- **한 장 한 메시지**, 근거는 2~5개. 넘치면 장을 나눈다(글자를 줄이지 않는다).
- 모든 장에 **발표자 노트**(말할 내용)를 쓴다. 화면에는 핵심만, 설명은 노트로.
- 숫자에는 단위·기준·출처를 붙인다. 출처는 아래 한 줄(9.5pt).
- 지어 낸 수치·사례는 쓰지 않는다. 예시 수치면 "(가상)"이라고 밝힌다.

## 2. 색: 중립색 + 장마다 포인트 색 하나

바탕은 흰색·연회색·검정, 글자는 거의 검정(#1D1D1F)과 회색 3단계. 여기에 **장(섹션)마다 내용에 맞는 포인트 색 하나**를 고른다.
한 장 안에서는 포인트 색이 하나뿐이어야 한다(표지·차례처럼 장 색을 미리 보여 주는 장은 예외).

| 내용 | 포인트 색 | 이유 |
|---|---|---|
| 제도·정책·법·공식 문서 | navy(남색) | 권위·안정 |
| 계획·설계·구조·과정 | teal(청록) | 설계도·도면의 차분함 |
| 데이터·분석·증거·디지털 | blue(파랑) | 명료·신뢰 |
| 고쳐 쓰기·주의·문제점·강조 | crimson(진홍) | 빨간 펜 |
| 성장·윤리·신뢰·완성·환경 | green(초록) | 안전·성장 |
| 일정·마감·실행·점검 | amber(호박) | 시간·에너지 |
| 부록·요약·참고 | graphite(흑연) | 절제 |
| 창의·문화·예술 | violet(보라) | 아껴 쓴다(보라는 'AI 느낌'이 나기 쉽다) |

- **표지와 마지막 장은 같은 대표 색**으로 처음과 끝을 맞춘다.
- **데이터 그래프 색은 장 색과 따로**: 덱 전체에서 같은 뜻에 같은 색(예: 사전=옅은 파랑, 사후=진한 파랑).
- 작은 글자(24pt 미만)에 포인트 색을 쓰면 엔진이 대비가 되는 진한 색으로 바꾼다. 흰 글자가 올라간 포인트 색 면도 자동으로 진하게 바뀐다.
- **하지 않는 것**: 그라데이션, 무지개색, 보라→파랑 흐름, 그림자 남발, 이모지 아이콘, 아이보리 바탕+코랄, 장식용 색 띠, 제목 밑줄 장식, 유리 효과.

## 3. 구성: 반복을 피하고 리듬을 만든다

- **같은 구성 3장 연속 금지.** 표·흐름·큰 숫자·비교·사진·한 문장·인용·시간선을 섞는다.
- **카드 격자는 정말 나란한 정보일 때만.** 그 밖에는 선으로 나눈 목록(list2)이나 번호 행(rows)이 덜 'AI 같다'.
- 장의 리듬: `장 표지 → 질문(한 문장) → 근거 슬라이드 3~8장 → 정리(한 문장·실습·점검)`.
- 장 표지는 사진 위치를 좌우로 번갈아 둔다. 장마다 다른 사진을 쓰고, 같은 사진을 두 번 쓰지 않는다.
- 사진은 **과정이 보이는 장면**(회의·수업·작업). 사진 위에 글자를 올릴 때는 어둡게 덮는다(dim 0.4~0.5).
- 강조 면(장 색으로 칠한 상자)은 한 장에 하나.

## 4. 글자(한국어)

- 글꼴은 Pretendard 한 가족(굵기만 바꾼다). 숫자는 ExtraBold, 큰 장 번호는 Light.
- 크기: 제목 28~34pt · 본문 15~18pt · 표 12.5~14pt · 보조 12~13pt · 출처·꼬리말 9~9.5pt. 9pt 미만 금지.
- **줄바꿈은 어절 단위**(엔진이 자동으로 나눈다). 닫는 괄호·쉼표로 줄이 시작되지 않는다.
- 한 줄 끝에 한두 글자만 남으면 문장을 다듬거나 상자 폭을 바꾼다.
- 굵게(`**강조**`)는 한 문단에 한두 군데. 강조가 많으면 아무것도 강조되지 않는다.
- 날짜 `2026. 10. 5.`, 숫자와 단위는 붙여 쓴다(`50쪽`, `78.3%`).

## 5. 배치(960×540pt 기준)

- 좌우 여백 44pt. 머리말 34 · 제목 56 · 이끄는 말 98 · **본문 148~470** · 출처 478 · 꼬리말 513.
- 왼쪽 맞춤이 기본. 가운데 맞춤은 한 문장 슬라이드에만.
- 오른쪽 아래 **진행 막대**(장마다 그 장 색)와 쪽 번호로 지금 위치를 보여 준다.
- 사진은 가장자리까지 꽉 채우거나(반쪽 면) 모서리 반경을 테마와 같게.

## 6. 엔진이 자동으로 점검하는 것

| 점검 | 기준 |
|---|---|
| 넘침 | 글자를 줄여도 상자에 안 들어가면 오류 |
| 겹침 | 글자끼리 3pt 넘게 겹치면 오류 |
| 벗어남 | 슬라이드 밖으로 나간 글자 |
| 작은 글자 | 9pt 미만 |
| 대비 | 작은 글자 4.5:1, 큰 글자 3:1, 9~10pt 메모성 글자 2.4:1 |
| 색 수 | 한 장에 포인트 색 가족 둘 이상 |
| 반복 | 같은 종류 3장 연속 |
| 노트 | 발표자 노트 없음 |
| 실측(PowerPoint 있을 때) | PowerPoint 가 그린 실제 줄 수 = 엔진 예상 줄 수 |

점검 결과의 오류·경고는 모두 고친 뒤 넘긴다.
